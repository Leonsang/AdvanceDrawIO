# AdvanceDrawIO v0.2.0

## Los 770 ejemplos oficiales de jgraph como referencia

- `find_examples` y `get_example`: catálogo clasificado en 23 tipos, con la receta de estilos por rol,
  las capas, los textos reemplazables y la imagen de cada ejemplo.
- `search_shapes`: stencils oficiales de AWS, Azure, Cisco, Kubernetes, BPMN y más, listos para `style`.
- **Tres modos**: spec (`build_diagram`), Mermaid (`build_from_mermaid`) y plantilla (`build_from_example`).
- La revisión trata las tablas (por ejemplo, las de un ER) como un solo nodo.

## CLI

- `advancedrawio-build` acepta `.json` (spec), `.mmd` (Mermaid) y `.plantilla.json` (plantilla).
- Imprime la revisión junto a las rutas, y `--min-score N` sale con código 1 si no se alcanza.

## Seguridad

Los argumentos de las tools los decide un LLM, que puede estar influido por contenido no confiable.
Ahora se tratan como entrada no confiable (detalle en [SECURITY.md](../SECURITY.md)):

- **Rutas hacia draw.io siempre absolutas.** Una ruta que empezaba con `-` llegaba al CLI como opción de
  Electron/Chromium, y algunas de esas opciones ejecutan comandos. `render` solo acepta archivos que existen.
- **Ciclos entre zonas.** Un `parent` circular pasaba la validación y colgaba el servidor; ahora es un
  error de spec.
- **Sandbox de Chromium.** `--no-sandbox` solo se usa como root (contenedores y CI) o con
  `ADVANCEDRAWIO_NO_SANDBOX=1`.
- **Nombres de salida y archivos comprimidos.** `name` ya no puede escribir fuera de la carpeta de salida,
  y cada página comprimida de un `.drawio` tiene un tope de 50 MB.

## Correcciones

- Modo plantilla: un reemplazo corto (por ejemplo `S` → `F`) se aplicaba dentro de textos ya reemplazados
  (`PAGOS` → `PAGOF`). Ahora una coincidencia exacta cierra la celda y los fragmentos se reemplazan como
  palabras completas.

## Calidad y proyecto

- CI en Linux, macOS y Windows (Python 3.10 y 3.13), con ruff y las acciones de GitHub en sus versiones actuales.
- Job `e2e` con draw.io Desktop real: corre todos los tests y construye cada ejemplo con revisión mínima de 85.
- **Galería automática** en `docs/galeria`: PNG, `.drawio` y puntaje de cada ejemplo, regenerada por el CI.
- Ejemplos nuevos: API serverless en AWS, asistente multiagente en GCP, contexto C4, modelo ER en
  Mermaid, DOFA en modo plantilla y el diagrama de cómo funciona el propio servidor.
- Documentación del spec, de la revisión y de las sesiones en la nube de Claude Code.
- Identidad visual, licencia MIT, plantillas de issues y PR, y release automático por tag.

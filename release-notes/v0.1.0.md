# AdvanceDrawIO v0.1.0

Primera versión: un servidor MCP que genera diagramas draw.io de arquitectura a partir de un spec JSON.

- **Layout ELK** con zonas anidadas, usando el CLI de draw.io Desktop. El spec no lleva coordenadas.
- **Iconos oficiales** del índice de shapes de draw.io, más SVG propios en `icons/`.
- **Tarjetas al estilo de la plantilla GCP oficial**: icono, función y producto.
- **Capas por flujo** con leyenda clicable (`data:action/json`), pasos numerados, notas y título.
- **Revisión objetiva** (`lint_diagram`) con puntaje de 0 a 100 y arreglos sugeridos.
- **Agente `drawio-architect`**, como subagente de Claude Code y como prompt MCP `arquitecto_drawio`.
- Tools `search_icons`, `spec_reference`, `build_diagram`, `lint_diagram`, `render` y `doctor`.
